NEKSUS DRIVER ANDROID - QUICK START

1) Upload this v5 repository to GitHub.
2) Render keeps Root Directory = backend.
3) Vercel keeps Root Directory = frontend.
4) Let Render redeploy FIRST because backend v5 adds driver mobile endpoints.
5) In GitHub open Actions -> NEKSUS Android APK -> Run workflow.
6) When green, open that workflow run -> Artifacts -> NEKSUS-Driver-debug.
7) Download the ZIP, extract app-debug.apk, and install it on an Android phone.
8) In the NEKSUS admin website create a driver with Username + Password + License + Vehicle.
9) Open the Android app and sign in with that driver's username/password.

Backend already configured in the app:
https://neksuseldv1.onrender.com

The app uses the same PostgreSQL database as the website. Driver status changes in the app update the admin site through the backend/database realtime path.

NOTE: This is an MVP integration build, not a certified ELD device/app. Bluetooth/ECM automatic driving, engine-hour/odometer ingestion, FMCSA transfer/output, malfunction diagnostics, and validated HOS logic require additional implementation and testing.
